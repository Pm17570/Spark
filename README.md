# SPARK — ระบบสอบออนไลน์ (สอบเดี่ยว)

Next.js + **SQLite (SQL)** · รองรับ **LaTeX** · โครงสร้างข้อสอบ: **ข้อสอบ → วิชา → ข้อใหญ่ → ข้อย่อย**

## ติดตั้งและรัน
ต้องมี Node.js 20 ขึ้นไป

```bash
npm install
npm run build
npm start          # เปิดที่ http://localhost:3000
```
ทดลองแก้โค้ด: `npm run dev`

> **Windows:** ถ้า PowerShell ฟ้อง `npm.ps1 cannot be loaded` ให้ใช้ `npm.cmd install`, `npm.cmd run build`, `npm.cmd start` หรือเปิด Command Prompt (cmd) แทน

ครั้งแรกที่เปิดเซิร์ฟเวอร์ ระบบจะ
- สร้างฐานข้อมูล `data/spark.db`
- สุ่ม **รหัสผ่านแอดมิน** แสดงใน console และเก็บที่ `data/ADMIN-PASSWORD.txt` (เข้าที่ `/admin` แล้วกด “เปลี่ยนรหัสผ่าน”, จากนั้นลบไฟล์นี้)
  หรือกำหนดเองด้วย `ADMIN_PASSWORD=...` ก่อนรัน
- สร้าง **ข้อสอบตัวอย่าง** (3 วิชา ครบทุกรูปแบบ) พร้อมรหัสผู้เข้าสอบตัวอย่าง 5 รหัส แสดงใน console

ลืมรหัสผ่านแอดมิน: `node scripts/set-admin-password.mjs "รหัสใหม่อย่างน้อย 8 ตัว"`

## วิธีใช้
**แอดมิน** (`/admin`)
1. สร้างข้อสอบ → แท็บ **ข้อสอบ**: เพิ่มวิชา / ข้อใหญ่ / ข้อย่อย, แนบรูป, ใส่สูตร (ปุ่ม “∑ สูตร” มีตัวอย่างสูตรให้และมีพรีวิวสด) แล้วกด 💾 บันทึก
2. แท็บ **ผู้เข้าสอบ & รหัส**: สุ่มรหัสตามจำนวน / นำเข้ารายชื่อ (“ชื่อ, โรงเรียน”) / ดาวน์โหลด CSV / พิมพ์สลิปรหัส
3. แท็บ **ควบคุมการสอบ**: เปิด-ปิดสอบ, ตั้งเวลาเริ่ม/ปิด/เวลาต่อคน, เพิ่มเวลา, ติดตามผู้สอบสด (+5 นาที, ให้ทำต่อ, รีเซ็ต)
4. แท็บ **ตรวจ**: ระบบตรวจอัตโนมัติให้ทุกข้อที่มีเฉลย ข้อที่ตั้งเป็น “กรรมการตรวจเอง” ตรวจทีละข้อหรือทีละคน
5. แท็บ **สรุปผล**: อันดับ (คะแนนมากสุด เท่ากันดูเวลาน้อยกว่า), คะแนนรายวิชา, วิเคราะห์รายข้อ, CSV

**ผู้เข้าสอบ** (หน้าแรก `/`): กรอกรหัส 8 ตัว (เช่น `K7QM-3XP9`) — 1 รหัส = 1 คน ใช้ได้ครั้งละ 1 อุปกรณ์ (เข้าใหม่จะเตะเครื่องเก่าออก) คำตอบบันทึกอัตโนมัติ หมดเวลาแล้วส่งให้เอง

## ผู้ช่วยดูแล (Moderator) และข้อความ
- แอดมินสร้างบัญชี moderator ได้หลายคนที่เมนู **ผู้ช่วยดูแล** (`/admin/moderators`) — ล็อกอินที่ `/admin` โดยกรอก **ชื่อผู้ใช้ + รหัสผ่าน** (ผู้ดูแลหลักเว้นช่องชื่อผู้ใช้ไว้)
- Moderator **ทำได้:** ดูสถานะสด, เพิ่มเวลาให้รายคน/ให้ทำต่อ, ตรวจข้อสอบ, ดูสรุปผล, ส่ง/รับข้อความ · **ทำไม่ได้:** แก้ข้อสอบ, ตั้งเวลา/เปิด-ปิดสอบ, ดูรหัสเข้าสอบ, ลบ/รีเซ็ต, จัดการบัญชี
- **ส่งข้อความ (DM):** แอดมิน/moderator เปิดแท็บ “💬 ข้อความ” ของข้อสอบ เลือกผู้เข้าสอบแล้วพิมพ์ — ข้อความเด้งเป็นแจ้งเตือนบนหน้าจอผู้เข้าสอบ (ภายใน ~6 วินาที)
- **ผู้เข้าสอบทักทีมงาน:** ปุ่ม 💬 มุมขวาล่าง — ข้อความเด้งแจ้งเตือน (ป๊อปอัป + เสียง + ตัวเลขบนแถบบน) ให้แอดมินและ moderator ทุกคนที่เปิดหน้า `/admin` อยู่ (ภายใน ~4 วินาที)
- จำกัดการส่งของผู้เข้าสอบ 6 ข้อความ/นาที (กันสแปม) ข้อความยาวสุด 500 ตัวอักษร

## รหัสเข้าสอบ
สุ่ม 8 ตัวด้วย `crypto.randomInt` จากอักษร 31 ตัว (ตัด 0/O/1/I/L) ≈ 8.5×10¹¹ แบบ ไม่ซ้ำกันเพราะมี UNIQUE ใน SQL (ชนแล้วสุ่มใหม่อัตโนมัติ) พิมพ์ตัวเล็ก/ใหญ่/มีขีดหรือไม่มีก็ได้

## เขียนโจทย์ด้วย LaTeX
`$x^2+1$` (ในบรรทัด) · `$$\int_0^1 x^2\,dx$$` (กลางบรรทัด) · `\(…\)` `\[…\]` · พิมพ์ `\$` เมื่อต้องการเครื่องหมายดอลลาร์จริง ใช้ได้ในโจทย์, ตัวเลือก, ข้อความถูก/ผิด, เติมคำ, จับคู่
เติมคำ: เขียนคำตอบในช่องว่างเป็น `[[คำตอบ]]` หรือ `[[คำตอบ|คำที่รับได้อีกแบบ]]`

## รูปแบบข้อย่อย
ปรนัย (เลือกจำนวนตัวเลือกได้, ถูกหลายข้อ/เช็คบอกซ์, ให้คะแนนบางส่วน) · ถูก/ผิด (เลือกให้แก้ข้อความได้) · ลากคำมาเติม · จับคู่ · พิมพ์ตอบ (ตรง/มีคำ/ตัวเลขพร้อมช่วงคลาดเคลื่อน/ตรวจเอง)
ข้อใหญ่เลือกได้ว่าข้อย่อย **อยู่หน้าเดียวกัน** หรือ **แยกคนละหน้า**

## ข้อมูลและการสำรอง
ทุกอย่างอยู่ในโฟลเดอร์ `data/` (`spark.db` + `uploads/`) — สำรองโดยคัดลอกทั้งโฟลเดอร์ (ปิดเซิร์ฟเวอร์ก่อน) เปลี่ยนที่เก็บด้วย `DATA_DIR=/path`

## พื้นหลัง
รูปพื้นหลังคือ `public/spark-bg.jpg` — แทนที่ไฟล์นี้ด้วยรูปอื่นได้ทันที

## ใช้งานจริง — ข้อแนะนำ
- ใช้ผ่าน **HTTPS** (reverse proxy เช่น Nginx/Caddy) และส่ง header `X-Forwarded-For`/`X-Forwarded-Proto`
- ระบบใช้ SQLite บนเซิร์ฟเวอร์เครื่องเดียว (โหมด WAL) รองรับผู้สอบพร้อมกันได้ระดับร้อยถึงราวพันคนสำหรับข้อสอบทั่วไป — ถ้าต้องการหลายเซิร์ฟเวอร์ต้องย้ายไป PostgreSQL/MySQL (SQL อยู่ที่ `lib/repo.js` ที่เดียว)
- ตัวจำกัดความถี่ล็อกอินอยู่ในหน่วยความจำ (รีสตาร์ทแล้วรีเซ็ต)
- ทดสอบโหลดก่อนวันสอบจริงเสมอ
